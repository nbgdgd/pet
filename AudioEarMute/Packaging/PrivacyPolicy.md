# Privacy Policy — AudioEarMute

Last updated: 28 July 2026

## Summary

AudioEarMute does not collect, transmit or store any personal data.

## What the app does with data

AudioEarMute is a local utility. It reads and changes the per-channel volume of audio
sessions on your computer's default output device. It does not record, capture or process
audio content.

The app stores exactly one file on your computer:

```
%APPDATA%\AudioEarMute\config.json
```

That file holds your chosen mode (stereo, left only or right only) and your hotkey
preferences. It never leaves your computer. Uninstalling the app and deleting that folder
removes it completely.

## Network

AudioEarMute makes no network connections. It has no update checker, no analytics, no
crash reporting and no advertising.

## Third parties

No data is shared with anyone, because none is collected.

## Permissions

The app requests a single Windows capability, `runFullTrust`. Every packaged Win32
desktop application requires it. AudioEarMute uses it only to call the Windows Core Audio
API for the current user's audio mixer.

## Children

The app collects no data from anyone, including children.

If this policy ever changes, the updated version will be published at the same address
