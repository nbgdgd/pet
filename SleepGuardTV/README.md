# SleepGuard TV

Android TV приложение для автоматической паузы видео при засыпании пользователя.

## Описание

Приложение работает в фоне через Foreground Service и периодически показывает overlay-окно с вопросом "Ты спишь?". Если пользователь не нажимает кнопку "Я не сплю" за отведённое время, видео перематывается назад и ставится на паузу.

## Возможности

- Два способа управления чужим плеером:
  - **MediaSession** (основной) — точная перемотка и пауза через MediaSession API
  - **Медиа-кнопки** (fallback) — через dispatchMediaKeyEvent, если MediaSession недоступен
- Настройка интервала проверки (5-120 минут)
- Настройка времени ожидания ответа (10-180 секунд)
- Настройка величины перемотки назад (5-60 минут)
- Настройка длительности удержания кнопки REWIND (500-10000 мс)
- Постоянное уведомление с указанием активного способа управления
- Полная поддержка навигации D-pad (пульт ДУ)

## Требования

- Android TV приставка или телевизор с Android TV
- Android 5.0 (API 21) или выше
- Разрешение "Уведомления" (Notification Listener)
- Разрешение "Поверх других приложений" (Overlay)

## Сборка

1. Откройте проект в Android Studio
2. Дождитесь завершения синхронизации Gradle
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**
4. APK будет создан в `app/build/outputs/apk/debug/`

## Установка на Android TV

### Способ 1: Через USB

1. Скопируйте APK-файл на USB-накопитель
2. Подключите USB к TV-приставке
3. Откройте файловый менеджер на приставке
4. Найдите APK-файл и запустите установку
5. Если установка блокируется, включите "Неизвестные источники" в настройках

### Способ 2: Через ADB

1. Включите "Отладка по USB" в настройках разработчика на приставке
2. Подключите приставку к компьютеру через USB
3. Выполните команду:
   ```bash
   adb install SleepGuardTV.apk
   ```

### Способ 3: Через файловый менеджер на TV

1. Скопируйте APK на облачное хранилище (Google Drive, и т.д.)
2. На приставке откройте файловый менеджер
3. Скачайте APK с облачного хранилища
4. Запустите установку

## Выдача разрешений

**ВАЖНО:** После установки необходимо вручную выдать два разрешения. Приложение запросит их автоматически, но на Android TV эти разрешения нужно подтверждать вручную через настройки.

### Разрешение 1: Уведомления (Notification Listener)

Это разрешение необходимо для доступа к MediaSession других приложений (VK Видео, YouTube и т.д.).

**Как найти на Android TV:**

1. Откройте **Настройки** (Settings) на приставке
2. Перейдите в **Приложения** (Apps)
3. Выберите **Особый доступ** (Special access) или **Дополнительные настройки** (Additional settings)
4. Найдите и выберите **Уведомления** (Notifications) или **Notification access**
5. В списке найдите **SleepGuard TV**
6. Включите переключатель рядом с приложением
7. Подтвердите предупреждение системы

**Альтернативный путь (зависит от прошивки):**

1. **Настройки** → **Приложения** → **Особый доступ** → **Управление уведомлениями** → **Доступ к уведомлениям**
2. Или: **Настройки** → **Приложения** → **Специальные возможности** → **Доступ к уведомлениям**

### Разрешение 2: Поверх других приложений (Overlay)

Это разрешение необходимо для показа overlay-окна "Ты спишь?" поверх видео.

**Как найти на Android TV:**

1. Откройте **Настройки** (Settings) на приставке
2. Перейдите в **Приложения** (Apps)
3. Выберите **Особый доступ** (Special access)
4. Найдите и выберите **Поверх других приложений** (Display over other apps) или **Отображение поверх других приложений**
5. В списке найдите **SleepGuard TV**
6. Включите переключатель

**Альтернативный путь:**

1. **Настройки** → **Приложения** → **Особый доступ** → **Отображение поверх других приложений**
2. Или: **Настройки** → **Приложения** → **Специальные возможности** → **Отображение поверх других приложений**

### Быстрый доступ к разрешениям из приложения

В главном экране приложения есть кнопка **"Разрешения"**, которая открывает экран настроек с прямой ссылкой на настройки overlay-разрешения.

## Настройка

После выдачи разрешений:

1. Откройте приложение SleepGuard TV
2. Нажмите кнопку **"Настройки"**
3. Настройте параметры:
   - **Интервал проверки** — как часто показывать вопрос (по умолчанию 60 мин)
   - **Время ожидания** — сколько секунд ждать ответа (по умолчанию 60 сек)
   - **Перемотка назад** — на сколько минут перематывать (по умолчанию 40 мин)
   - **Удержание REWIND** — длительность нажатия кнопки перемотки (по умолчанию 1000 мс)
4. Включите переключатель **"Включить слежение"**
5. Нажмите кнопку **"Назад"** на пульте

## Использование

1. Запустите видео в любом плеере (YouTube, VK Видео, и т.д.)
2. Откройте SleepGuard TV и нажмите "Запустить слежение"
3. Переключитесь обратно на плеер
4. Каждые N минут будет появляться overlay-окно
5. Нажмите ОК на пульте, если вы не спите
6. Если не нажмёте — видео перемотается и встанет на паузу

|-----------|-------------|
| `BIND_NOTIFICATION_LISTENER_SERVICE` | Доступ к MediaSession других приложений |
| `SYSTEM_ALERT_WINDOW` | Показ overlay-окна поверх видео |
| `FOREGROUND_SERVICE` | Фоновая работа сервиса |
| `WAKE_LOCK` | Предотвращение засыпания сервиса |

## Решение проблем

### Приложение не видит плеер

- Убедитесь, что выдано разрешение "Уведомления" (Notification Listener)
- Убедитесь, что плеер активно воспроизводит видео
- Проверьте в уведомлении сервиса текущий способ управления

### Overlay-окно не появляется

- Убедитесь, что выдано разрешение "Поверх других приложений"
- Проверьте, что мониторинг включён в настройках

### Кнопка "Я не сплю" не реагирует

- Убедитесь, что фокус находится на кнопке (выделена рамкой)
- Нажмите центральную кнопку (OK/Enter) на пульте

### Перемотка работает неточно

- Это нормально для способа "Медиа-кнопки" — точность зависит от плеера
- Попробуйте увеличить длительность удержания REWIND в настройках
- Если плеер поддерживает MediaSession — приложение автоматически переключится
