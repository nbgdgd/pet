1. ОБЗОР ПРОЕКТА
======================================================================
- Офлайн голосовой ассистент типа JARVIS для Windows
- Стек: Vosk STT (распознавание русской речи) + Piper TTS (синтез речи)
- Ввод: микрофон (sounddevice)
- Вывод: звук (sounddevice + winsound для WAV-файлов)
- Маршрутизация команд: fuzzy matching через rapidfuzz
- 85 групп команд, 293 фразовых варианта


2. ИСТОРИЯ БАГОВ И ИСПРАВЛЕНИЙ
======================================================================

2.1 УБИЙСТВО EXPLORER.EXE (Windows Shell)
------------------------------------------
  Баг:  close_explorer() использовал taskkill /f /im explorer.exe
        Это убивало рабочий стол, панель задач, пуск.
  Фикс: Заменён на PowerShell COM Shell.Application.Windows().Quit()
        Закрывает только окна проводника, не трогая шелл.
  Файл: commands/apps.py -> close_explorer()

2.2 РАЗДЕЛИТЕЛЬ "И" РЕЗАЛ СЛОВА ВНУТРИ
------------------------------------------
  Баг:  split_phrases() делил текст по "и" без границ слов
        "тише" -> "т" + "ше"
  Фикс: Добавлено \b (word boundary) в re.split
  Файл: commands/router.py -> split_phrases()

2.3 NONLOCAL SCOPE ERROR В main.py
------------------------------------------
  Баг:  Использование nonlocal внутри вложенной функции
  Фикс: Переписан на класс Assistant
  Файл: main.py

2.4 МИКРОФОН НЕ РАБОТАЛ (УРОВЕНЬ 12)
------------------------------------------
  Баг:  soundcore Space One выдавал peak <= 12
  Причина: Не тот индекс устройства
  Фикс: Добавлены флаги --list-mics, --device N, MICROPHONE_INDEX в config.py

2.5 VAD ПОРОГ ВЗЛЕТАЛ ПОСЛЕ TTS/ГОЛОСА (работало через раз)
------------------------------------------
  Баг:  После ответа ассистента noise_floor взлетал (микрофон ловил динамики),
        VAD порог становился слишком высоким -> следующая команда не слышалась
  Фикс: 
  - reset_audio() — очищает буфер и сбрасывает noise_floor в 0
  - Вызывается после каждого _play_voice() и tts.say()
  - Минимальный порог 30.0 (не даёт порогу застрять высоко)
  - Задержка 0.3с после сброса
  Файл: speech/stt.py -> reset_audio()

2.6 CLOSE_EXPLORER ПОДВИСАЛ (COM HANG)
------------------------------------------
  Баг:  GetActiveObject('Shell.Application').Windows() зависал
  Фикс: Замена на New-Object + CloseMainWindow() + timeout
  Файл: commands/apps.py -> close_explorer()

  Фикс: Все функции громкости возвращают текст ("Громкость 40", "Звук выключен")

  Файл: commands/volume.py

2.9 ПРОГРАММЫ НЕ НАХОДИЛИСЬ (Telegram, Firefox etc.)
------------------------------------------

  4. start <имя> — fallback
  - Добавлены пути для Firefox, Chrome, Edge, Telegram, Discord, Spotify, VS Code
  - Добавлены [LAUNCH] логи для отладки
  Файл: commands/apps.py -> _launch()

2.10 АНГЛИЙСКИЕ СЛОВА НЕ РАСПОЗНАВАЛИСЬ

2.11 СКРИНШОТ НЕ РАБОТАЛ (PS СКРИПТ СЛОМАН)

  winsound       - Воспроизведение WAV-файлов (JARVIS voice)

9. КРУПНОЕ ОБНОВЛЕНИЕ — 2026-07-27
======================================================================

РАСПОЗНАВАНИЕ РЕЧИ
  - Основной движок: GigaAM v3 (onnx-asr). ~8% WER против 22-31% у
    vosk-model-small-ru, ~90 мс на команду, только CPU, MIT.
  - Whisper (faster-whisper) как альтернатива: единственный офлайн-движок,
    выводящий латиницу латиницей; названия программ подсовываются
    через hotwords=.
  - Deepgram: соединение НИ РАЗУ не работало. listen.v2.connect —
    контекстный менеджер, а send_media вызывался у него самого вместо
    объекта из __enter__; ошибка гасилась `except: pass`. Исправлено,
    добавлены language_hint=[ru,en] и keyterm со списком программ.
  - Endpointing: silero-vad v6 вместо порога по громкости.
  - Один общий поток записи (speech/audio.py). Раньше пункт меню [V]
    открывал ВТОРОЙ RawInputStream на том же микрофоне, и два потребителя
    растаскивали кадры из общей очереди.
  - Убран busy-wait (while True без пауз жёг целое ядро).
  - Убран «кулдаун» 1.5 с, из-за которого listen_phrase мгновенно
    возвращал None, а пять таких None подряд навсегда переключали
    ассистента на самый слабый движок.
  - Шумовой порог больше не обновляется во время собственной речи.

СИНТЕЗ РЕЧИ
  - Silero v5.5 ru, 48 кГц, автоударения, «ё», вопросительная интонация.
    Piper и SAPI5 остались запасными.
  - Цифры произносятся словами, латиница читается по-русски (tts/rutext.py).
  - Убран sd.default.device = None, None — он сбрасывал и УСТРОЙСТВО ВВОДА,
    выбранный микрофон переставал использоваться после первой реплики.

РАСПОЗНАВАНИЕ КОМАНД
  - CONFIDENCE_THRESHOLD теперь реально работает. Раньше detect() при
    любом исходе возвращал лучшего кандидата, поэтому "открой aniblaze"
    запускал случайную команду с 40-60%.
  - Совпадение только по служебному глаголу больше не считается
    совпадением (GENERIC_TOKENS).
  - _short_alias_match не срабатывает на отдельном слове внутри фразы.
  - _substring_match сравнивает слова, а не голые подстроки.
  - fuzzy: token_sort_ratio вместо token_set_ratio, порог +8.
  - Нормализатор: один проход вместо ~160 последовательных re.sub.
  - SYNONYMS: убран дубликат "выключи" (побеждал shutdown, из-за чего
    "выключи телеграм" тянуло к выключению компьютера).
  - NOISE_WORDS: убраны "не"/"да"/"нет" — отрицание переворачивало смысл.
  - PHONETIC: убраны обрывки "дис", "теле", "лис".
  - registry.py: устранены 11 дублей вариантов и коллизия "гейминг".
  - voice_profile.match: сравнение по целым словам, а не по подстроке
    (шаблон "час" давал 100% на слове "сейчас").

ЗАПУСК И ЗАКРЫТИЕ ПРОГРАММ
  - commands/app_index.py: каталог всех программ Windows (Get-StartApps,
    ярлыки .lnk, App Paths, Uninstall). 457 программ на этой машине.
  - commands/translit.py: фонетический скелет RU<->LAT, поэтому
    "аниблейз", "а ни блэйз" и "aniblaze" — одна и та же программа.
  - commands/dynamic.py: "открой/закрой <что угодно>", поиск файлов
    и папок через индекс Windows Search.
  - commands/winlaunch.py: Popen DETACHED / ShellExecute / AppsFolder.
    os.system("start ...") убран везде — он мигал окном cmd и ломался
    на путях с пробелами.
  - commands/winproc.py: закрытие через WM_CLOSE с ожиданием, потом
    terminate. Своё дерево процессов исключено, поэтому "закрой cmd"
    больше не убивает консоль самого JARVIS.
  - close_calculator: реальное имя процесса CalculatorApp.exe
    (calculator.exe не существует, команда не работала никогда).
  - open_explorer: убран Marshal.GetActiveObject('Shell.Application'),
    который всегда бросал исключение.
  - close_explorer: закрывает окна, не убивая explorer.exe.

СИСТЕМА
  - gaming_mode: раньше завершал всё, чего не было в коротком белом
    списке — около 2/3 всех процессов, включая сам ассистент. Теперь
    закрывается явный список фоновых приложений плюс, опционально,
    процессы тяжелее 300 МБ; системные каталоги и чужие сессии не трогаются.
  - days_until: не падает в декабре (month=13 бросал ValueError раньше,
    чем срабатывала проверка month > 12) и понимает числа словами.
  - free_ram: минимально необходимые права вместо PROCESS_ALL_ACCESS,
    хендл закрывается всегда.

БЕЗОПАСНОСТЬ

ИНТЕРФЕЙС

  - Исправлены раскладочные клавиши: M -> "Ь", V -> "М".
