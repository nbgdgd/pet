# JARVIS Offline — голосовой ассистент для Windows

Офлайн-ассистент в стиле JARVIS на Python. Слушает микрофон, активируется
по слову «Джарвис», выполняет команды Windows и отвечает голосом.

## Что изменилось в этой версии

| Было | Стало |
|---|---|
| Vosk small ru, 22–31% ошибок, латиница невозможна в принципе | **GigaAM v3** (onnx-asr), ~8% ошибок, ~90 мс на команду, всё на CPU |
| Deepgram не отправлял в облако ни байта (`send_media` вызывался у контекстного менеджера) | соединение исправлено, добавлены `language_hint=[ru,en]` и `keyterm` со списком программ |
| Piper irina, 22 кГц | **Silero v5.5**, 48 кГц, автоударения, «ё», вопросительная интонация |
| Порог уверенности не работал — незнакомая фраза запускала случайную команду | порог обязателен, ниже порога — отказ |
| Открывались только ~15 вписанных вручную программ | **каталог всей Windows** (457 программ на этой машине), «открой aniblaze» работает |
| `taskkill /IM /F`, «закрой cmd» убивал сам JARVIS | WM_CLOSE с корректным завершением, своё дерево процессов исключено |
| Игровой режим завершал ~2/3 всех процессов, включая ассистент | закрывается явный список фоновых приложений |
| Два потока записи на одном микрофоне, busy-wait на всё ядро | один общий источник звука, silero-vad, блокирующее чтение |
| Ключ Deepgram лежал в исходниках | только из переменной окружения |

## Установка

```bash
pip install -r requirements.txt
```

Первый запуск сам скачает модель GigaAM v3 (~250 МБ) в `models/hf/`.

Модель синтеза `models/silero/v5_5_ru.pt` (145 МБ) — если её нет:

```bash
curl -L -o models/silero/v5_5_ru.pt https://models.silero.ai/models/tts/ru/v5_5_ru.pt
```

## Запуск

```bash
py jarvis_cmd.py
```

Отладочный режим: `py jarvis_cmd.py --debug`

## Настройка (config.py)

| Параметр | Значение |
|---|---|
| `STT_BACKEND` | `gigaam` (по умолчанию) · `whisper` · `vosk` · `deepgram` |
| `TTS_VOICE` | `eugene` `aidar` `xenia` `baya` `kseniya` (Silero) · `irina` `denis` `dmitri` (Piper) |
| `WAKE_WORD_REQUIRED` | ждать ли «джарвис» перед каждой командой |
| `CONFIDENCE_THRESHOLD` | 72 — ниже этого команда отклоняется |
| `MICROPHONE_INDEX` | номер устройства записи |

Переопределяется через окружение: `JARVIS_STT`, `JARVIS_VOICE`, `DEEPGRAM_API_KEY`.

## Голосовые команды

### Любая установленная программа

```
открой aniblaze          закрой аниблейз
открой obsidian          закрой стим
запусти телеграм         выключи спотифай
```

Название сопоставляется по звучанию, поэтому «аниблейз», «а ни блэйз»
и «aniblaze» ведут к одной и той же программе. Каталог обновляется
командой «обнови список программ» или пунктом меню **[A]**.

### Файлы и папки

```
открой файл отчёт        найди файл requirements
открой папку проекты
```

Работает через индекс Windows Search — тот же, что в меню Пуск.

### Система

| Фраза | Действие |
|---|---|
| «который час», «какая дата» | время и дата |
| «загрузка процессора», «загрузка ram», «место на диске» | состояние системы |
| «громче», «тише», «выключи звук», «громкость 30» | громкость |
| «покажи рабочий стол» | свернуть все окна |
| «сделай скриншот» | снимок в Pictures\Screenshots |
| «освободи память» | сброс рабочих наборов процессов |
| «игровой режим» | закрыть фоновые приложения |
| «сколько дней до тридцать первого» | счётчик дней (понимает числа словами) |
| «заблокируй экран», «выключи компьютер», «перезагрузи» | питание |

## Меню CMD

| Клавиша | Что делает |
|---|---|
| `M` | вкл/выкл микрофон |
| `V` | сказать команду сейчас |
| `T` | ввести команду текстом |
| `W` | переключить wake word |
| `L` / `E` | лог на экране / в блокноте |
| `R` | подхватить исправления из лога |
| `S` | монитор системы |
| `G` | сменить голос |
| `C` | все команды |
| `A` | каталог программ: показать, пересобрать, проверить название |
| `D` | разбор фразы — видно, почему сработала не та команда |

Пункт **[D]** — главный инструмент отладки распознавания: показывает
нормализованную фразу, всех кандидатов с процентами и порог отсечения.

│   └── rutext.py            цифры словами, латиница кириллицей
├── commands/
│   ├── registry.py          явные команды
│   ├── router.py            сопоставление с порогом
│   ├── normalizer.py        фонетика и мусорные слова
│   ├── app_index.py         каталог всех программ Windows
│   ├── dynamic.py           «открой/закрой что угодно», поиск файлов

## Известные ограничения

* «Освободи память» без прав администратора обрабатывает только процессы
  текущего пользователя — это ограничение Windows, не ассистента.
* GigaAM выдаёт кириллицу всегда: «aniblaze» приходит как «аниблейз».
  Для команд это неважно (сопоставление идёт по звучанию), но если нужен
  латинский текст дословно — ставьте `STT_BACKEND=whisper`.
* Поиск файлов зависит от индексации Windows Search. Если папка не
  проиндексирована, файл не найдётся.
* Сборка `.exe` с torch весит около 2 ГБ. Для лёгкой сборки уберите блок
  `torch` в `JARVIS.spec` и выберите голос Piper (`TTS_VOICE=irina`).
